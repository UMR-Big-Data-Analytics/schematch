# Schematch tools

The commands in `tools/` support Schematch itself. They use the current checkout
and explicitly selected inputs; no surrounding experiment repository or paper
dataset is required. Run commands from the repository root. Use `--help` for
the complete options of any command.

## Running and preparing data

| Tool | Purpose | Prerequisites |
|---|---|---|
| `run_schematch.py` | Launch the compiled Java application with the correct classpath separator on each platform. | Java build and `target/cp.txt`. |
| `check_setup.py` | Check Java, Maven, local libraries and configuration; optionally check evaluation packages. | Python standard library. |
| `prepare_datasets.py` | Download declared public releases, convert local releases or generate synthetic matching tasks. | Python standard library; downloads only when explicitly requested. |
| `transform_dataset.py` | Write recoded, relabelled, perturbed or column-permuted dataset copies while updating their ground truth. | Python standard library and prepared input data. |
| `audit_datasets.py` | Validate CSV files and ground-truth matrices using the same Java parsers as normal matching. | Compiled Java application. |
| `dataset_sources.json` | Dataset source URLs, checksums and preparation settings read by the preparation tools. | Data file, not an executable command. |

See [getting started](getting-started.md) for the first run and
[dataset preparation](datasets.md) for acquisition and conversion commands.
Generated inputs and outputs belong in ignored directories such as
`datasets-local/`, `results/` and `target/`.

## Evaluation and matcher development

| Tool | Purpose | Prerequisites |
|---|---|---|
| `evaluate_paper.py` | Evaluate captured raw scores, extract correspondences, compare paired methods and produce grouped summaries. | NumPy and SciPy. |
| `paper_metrics.py` | Shared numerical functions for ranking, extraction and assignment metrics. Imported by other tools. | NumPy and SciPy. |
| `cluster_units.py` | Build resampling groups by linking scenarios that share table contents. | Python standard library. |
| `positional_audit.py` | Check diagonal ground truth, extraction tie effects and matcher behavior under column permutations. | NumPy and SciPy; captured scores or rerun results. |
| `learned_combiner.py` | Train a combination of base-matcher scores on other scenario groups and export held-out score matrices. | NumPy, scikit-learn and labelled training data. |

The two `paper` filenames and the `paperEvaluation` settings are compatibility
names. Their functions apply to any supported matching task. The numerical
implementation, tests and fixtures are included locally; none import an
external scorer or fetch archived experiment results.

For example, captured score matrices can be evaluated again without rerunning
the matchers:

```shell
python tools/evaluate_paper.py --records results/my-run/paper_evaluation/input.jsonl --out results/my-analysis
```

The input path must identify a completed run. See [evaluation](evaluation.md)
for metric definitions, grouping and resampling settings. These analysis tools
are optional: a normal matching run does not train a combiner or perform
positional experiments.

## Development checks

| Tool or directory | Purpose |
|---|---|
| `check_project.py` | Check tracked files for broken documentation links, machine-specific paths and accidental generated artifacts. `--working-tree` also checks new files before staging. |
| `audit_matchers.py` | Generate/check the class catalog and ensure every Python method has a named Java adapter. |
| `audit_dataset_sources.py` | Generate/check the dataset catalog and validate local preparation declarations, URLs and checksum formats without downloading data. |
| `verify_standalone.py` | Run the Python regression suite, optionally blocking reads from a selected external directory when testing a separate copy. |
| `tests/` | Regression tests using small generated inputs and frozen numerical expectations. |
| `tests/fixtures/` | Test data and configuration-loading examples; not required benchmark inputs or a list of prescribed experiment methods. |
| `dataset_support/` | Reusable preparation and transformation modules called by the dataset tools. |

Routine checks:

```shell
python tools/check_project.py --working-tree
python tools/audit_matchers.py --check
python tools/audit_dataset_sources.py --check
python -m unittest discover -s tools/tests -v
mvn test
```

Run either catalog generator without `--check` after changing its classes or
source definitions. CI uses the same catalog checks and test suites.

Historical release-readiness records and prior experiment installation reports
are not part of the source repository. Reports generated by a user's own run
remain useful outputs, but they are not dependencies of the framework.
